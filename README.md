# Estante_Estrategica
Em vez de rolar o feed infinitamente, que tal transformar a tela do seu celular em uma estante de atalhos para notícias de primeira linha? De concursos e geopolítica a petróleo e criptomoedas, tudo organizado em uma estante visual que torna a leitura atraente. O ponto de partida ideal para dar fim ao desgaste neural das redes sociais!
